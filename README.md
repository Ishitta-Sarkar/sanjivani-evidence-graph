## Overview

**SANJIVANI** is an explainable biomedical intelligence platform designed to organize, explore, and interpret interconnected biomedical evidence.

The platform represents relationships among:

```text
Disease → Gene → Protein → Pathway → Therapeutic
```

Instead of presenting biomedical entities as isolated records, SANJIVANI enables users to investigate how they are connected, inspect the evidence supporting each relationship, identify biologically meaningful paths, and generate transparent research hypotheses.

Its current foundation combines:

- Biomedical knowledge representation
- Evidence-aware relationship mapping
- Graph-based reasoning
- Interactive network visualization
- Explainable biological path exploration
- Network analytics
- Research-oriented data export

SANJIVANI is designed as an extensible computational foundation for the future integration of machine learning, graph neural networks, multi-omics analysis, literature intelligence, and AI-assisted biomedical discovery workflows.

## Research Motivation

Biomedical knowledge is distributed across numerous databases, publications, pathway repositories, gene resources, and therapeutic datasets.

This fragmentation can make it difficult to investigate questions such as:

- Which genes, proteins, and pathways connect a disease to a therapeutic candidate?
- What biological route supports a possible drug-repurposing hypothesis?
- Which evidence source supports each relationship?
- How interpretable is a proposed biological connection?
- Can the complete reasoning path be exported for further analysis?

SANJIVANI addresses this problem by organizing biomedical relationships into an interactive, evidence-aware, and explainable graph structure.

The platform is intended to support:

- Bioinformatics education
- Computational biology research
- Systems biology exploration
- Biomedical network analysis
- Drug-repurposing hypothesis generation
- Explainable biomedical research workflows

## Core Capabilities

### 🔎 Biomedical Entity Search

Search and inspect diseases, genes, proteins, pathways, therapeutics, and other biomedical entities through a case-insensitive interface.

### 💊 Drug Recommendation Exploration

Explore therapeutic candidates associated with a selected disease through evidence-supported biomedical relationships.

Recommendations generated by SANJIVANI represent computational research hypotheses and must not be interpreted as clinical recommendations.

### 🧭 Multi-Hop Path Explorer

Identify the shortest available biological path between two biomedical entities.

Example:

```text
Metformin → AMPK → Glucose Metabolism → Type 2 Diabetes
```

### 🧠 Biological Path Explanation

Convert graph paths into readable explanations describing how the selected biomedical entities are connected.

### 📊 Path Confidence Scoring

Estimate the confidence of an explored path using the available relationship evidence and source coverage.

The confidence score is an internal interpretability and prioritization indicator. It is not a measure of clinical validity, therapeutic efficacy, or biological certainty.

### 🧾 Evidence Tracking

Inspect the evidence source associated with represented relationships.

Current source labels include resources such as:

- DrugBank
- KEGG
- GeneCards

### 🎛️ Evidence-Source Filtering

Filter biological paths and relationships according to selected evidence sources.

### 🕸️ Interactive Knowledge Graph

Explore biomedical relationships through an interactive and draggable network visualization.

### 📌 Entity Quick Facts

View important information about a selected biomedical entity, including:

- Entity name
- Entity type
- Number of connected relationships
- Associated evidence sources

### 📈 Graph Analytics

Examine structural properties of the biomedical network, including:

- Total entities
- Total relationships
- Entity-type distribution
- Evidence-source distribution
- Node connectivity
- Network composition

### 📥 Research Export

Export analysis results for reporting or further investigation:

- TXT biological path report
- CSV evidence table

## Example Research Workflow

A user may investigate a biological connection through the following workflow:

1. Select a disease or therapeutic entity.
2. Search the biomedical knowledge base.
3. Explore direct relationships.
4. Identify a multi-hop path between two entities.
5. Inspect the evidence supporting each connection.
6. Filter the path using selected evidence sources.
7. Review the generated biological explanation.
8. Examine the path confidence score.
9. Export the path report or evidence table.

Example path:

```text
Metformin
   ↓
AMPK
   ↓
Glucose Metabolism
   ↓
Type 2 Diabetes
```

This workflow supports transparent exploration because the represented reasoning path remains visible to the user.

## Dataset Structure

### `entities.csv`

Stores individual biomedical entities.

Example:

```csv
entity_id,name,entity_type
D001,Type 2 Diabetes,Disease
G001,INS,Gene
P001,AMPK,Protein
PW001,Glucose Metabolism,Pathway
DR001,Metformin,Drug
```

### `relationships.csv`

Stores evidence-labelled relationships between biomedical entities.

Example:

```csv
source,target,relationship,evidence_source
Metformin,AMPK,activates,DrugBank
AMPK,Glucose Metabolism,regulates,KEGG
Glucose Metabolism,Type 2 Diabetes,associated_with,KEGG
```

The example data illustrates the expected format and may not represent the complete repository dataset.

## Installation

### 1. Clone the Repository

```bash
git clone https://github.com/Ishitta-Sarkar/sanjivani-evidence-graph.git
```

### 2. Enter the Project Directory

```bash
cd sanjivani-evidence-graph
```

### 3. Create a Virtual Environment

#### Windows

```bash
python -m venv .venv
.venv\Scripts\activate
```

#### macOS or Linux

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 4. Install the Required Packages

```bash
pip install -r requirements.txt
```

### 5. Launch the Application

```bash
streamlit run app.py
```

The application should open in the default web browser.

## Scientific Limitations

SANJIVANI currently has several important limitations:

- The knowledge base is limited in size.
- Evidence labels do not independently confirm biological causality.
- Shortest graph paths are not necessarily the most biologically important paths.
- The confidence score is heuristic and has not been clinically validated.
- Drug recommendations are exploratory hypotheses.
- Biomedical relationships may require additional literature verification.
- The platform does not currently perform experimental validation.
- The platform does not currently train or deploy a predictive machine-learning model.
- Results depend on the completeness and quality of the supplied datasets.

These limitations are documented to preserve scientific transparency and prevent overinterpretation.
